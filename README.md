<h1>Помощник для macOS</h1>

Интуитивно понятное и стильное приложение-расписание для студентов, написанное на **Swift + SwiftUI**.  
С помощью встроенного HTML-парсера расписание автоматически подгружается с сайта **ruz.fa.ru**, моделируется внутри, а затем отображается в красивом UI с Glass-эффектами.

## 🧰 Стек технологий

### 🧠 Язык и платформа
- **Swift 5+** — основной язык разработки
- **iOS / SwiftUI** — нативный UI-фреймворк от Apple

### 🎨 Интерфейс
- **SwiftUI** — декларативная верстка интерфейса
- **Glass / Blur Effects** — визуальные эффекты стеклянных карточек
- **SwiftUI Preview** — быстрый UI-девелопмент и отладка

### 🧩 Архитектура и подходы
- **MVVM (light)** — разделение логики и UI
- **Value Types** — `struct` + `enum` для предсказуемых моделей
- **Identifiable / Hashable** — эффективная работа со списками
- **Dependency Isolation** — парсер не зависит от UI

## 📌 Основные фичи

✅ Поддержка реального расписания с **ruz.fa.ru**  
✅ Красивый интерфейс на **SwiftUI** с эффектом стекла  
✅ Чёткая архитектура моделей  
✅ Поддержка уроков + перерывов  
✅ Лёгкая модификация и расширение  
✅ Мок-данные для превью и отладки

## 🔎 Модели подробно

### 🧱 DaySchedule
Хранит набор уроков на **конкретный день**.

### 📘 Lesson
Основная модель занятия:

- Название
- Время начала/окончания
- Тип
- Аудитория / Онлайн
- Преподаватель и группа

### ⏱ LessonBreakInfo
Данные о **перерывах** между уроками, чтобы правильно визуализировать расписание.

### 📍 LessonLocation
Расположение занятия — корпус, номер аудитории, либо онлайн.

### 🧠 LessonKind
Тип занятия: лекция, практика, семинар и др.

### 📌 LessonScheduleItem
Универсальная сущность для UI: урок или перерыв.

## 🖼 UI Компоненты

### ✨ GlassView
Компонент UI с эффектом стекла  
(используется для карточек уроков).

### 📅 ScheduleView
Основной экран — календарь/список уроков.
